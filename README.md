# Sistema de Gestión de Eventos

Un moderno y elegante sistema para la gestión de eventos, construido con React, Vite y Vanilla CSS.

## Características Principales

*   **Interfaz Premium:** Diseño moderno con *glassmorphism*, modo oscuro y animaciones fluidas.
*   **Gestión Integral (CRUD):** Crea, visualiza, edita y elimina eventos de manera intuitiva.
*   **Calendario Interactivo:** Visualiza tus eventos en un calendario personalizado.
*   **Control de Asistentes:** Registra y administra los participantes para cada evento de forma independiente.
*   **Estado Global:** Implementación eficiente usando React Context API.
*   **Persistencia de Datos:** Tus eventos y asistentes se guardan automáticamente en tu navegador usando `localStorage`.

## Tecnologías Utilizadas

*   React 19
*   Vite
*   React Router DOM
*   Lucide React (Iconos)
*   Date-fns (Manejo de fechas)
*   Vanilla CSS

## Cómo ejecutar el proyecto localmente

1.  Asegúrate de tener Node.js instalado (se recomienda versión 22+).
2.  Clona el repositorio.
3.  Abre una terminal en la carpeta del proyecto.
4.  Instala las dependencias:
    ```bash
    npm install
    ```
5.  Inicia el servidor de desarrollo:
    ```bash
    npm run dev
    ```

## Despliegue

Este proyecto está optimizado para ser desplegado fácilmente en plataformas como Vercel o Netlify.
